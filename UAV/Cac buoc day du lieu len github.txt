Mở cửa sổ Terminal (MINGW64) tại thư mục chứa dữ liệu của bạn và chạy lệnh:
git init

Bước 2: Thiết lập danh tính (Chỉ làm 1 lần đầu)
git config --global user.email "9620205.22.014@ncs.hcmuaf.edu.vn"
git config --global user.name "gisvn"


Bước 3: Kết nối với GitHub (Chỉ làm 1 lần đầu)
git remote add origin https://github.com/gisvn/data.git

Bước 4: Chọn dữ liệu chuẩn bị gửi đi (Staging)
Đưa tất cả tệp trong thư mục lên: git add .
Hoặc chỉ đưa một tệp cụ thể: git add Index.html

Bước 5: Đóng gói và ghi chú (Commit)
git commit -m "Noi dung day len"


Bước 6: Đẩy dữ liệu lên GitHub (Push)
Trước khi push, hãy đảm bảo bạn đang ở nhánh main:

git branch -M main

Sau đó đẩy dữ liệu lên:
git push -u origin main

git push
